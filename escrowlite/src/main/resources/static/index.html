About EscrowLite

EscrowLite

EscrowLite is a milestone-based freelance payment release tracker.

A project can be divided into multiple milestones. The freelancer delivers each milestone, the client approves it, and then the payment can be released.


Workflow

Project → Milestone → Deliver → Approve → Release Payment
